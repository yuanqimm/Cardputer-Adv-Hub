# A 方案 UI 实现

用户选择参考图配色版 A：亮橙实心选中卡片、银白文字、石墨黑背景、少量绿色状态提示。参考稿位于本机 `output/imagegen/ui-review-reference-v2/A-*.png`；生图不是固件素材，页面由原生绘图指令实现。

## 共用组件

颜色定义集中在 `src/core/Ui.cpp`：背景 #181B19、面板 #262B28、边线 #454D48、橙色 #F57C00、正文 #EDF1F2、辅助文字 #A8B0B6。选中项统一深色文字，避免银白字与橙底对比不足。实际屏幕沿用8位帧缓冲，色阶会量化，不能将效果图色彩视为逐像素输出保证。

- 保留 240×135、32400 字节帧缓冲及内容哈希抑制重复刷屏。
- 标题占 y=0–17，内容占 y=18–120，底部快捷键占 y=122–134。
- `label` 限宽并省略过长文字，不自动换行；临时缓冲在栈上，不增加常驻堆分配。大字号绘制后恢复字号1。
- `card`、`progress`、`scrollBar` 共用；16×16 线图标为本项目原创，直接画点线，无位图资源和额外帧缓冲。

## 页面适配

- 主页保持2列3行、四方向选择，Settings 固定第六项。文字缩写图标换为线图标，焦点使用橙底深色字。
- Wi-Fi 同屏5条更宽松的卡片，滚动显示已有扫描结果，右侧滚动条及当前序号表示位置；不会缩小扫描缓存。历史页保留最多6条。
- Wi-Fi 信息分组显示 SSID/IP/GW/MASK/DNS，RSSI 独立显示，橙色入口仍由 I 手动登录SSH。真实运行状态/错误仍显示。
- SSH登录继续使用原来逐字段的主机、用户名、密码流程；受小屏限制，不照搬效果图三行同时编辑。长输入显示末尾，密码继续由服务层提供掩码。终端保留完整38列×12行，不使用会吞掉末列的通用限宽行。
- 键盘模式橙色卡片，下方USB/BLE状态与配对名；诊断页保留。N2身份、配对、输入路由不变。
- 红外3×3按键卡片，数字键发射后高亮最近按键；切换/重载设备时清除高亮。没有新增方向键发射或学习能力。
- SD浏览与菜单改为每屏5行、滚动条、橙色选中和文件夹标记。文件系统分页仍由原服务完成。菜单标题显示当前对象，避免残留上次对象名称。
- 音频独立文件名、放大计时、音量和文件读取进度。图片/视频保留文件名行，绘制区域改为 y=34–106，底部状态不覆盖画面，仍保持比例居中。
- Recorder上方文件名、中部计时/状态、下方频谱及独立提示行。频谱高度限制在面板内；底栏按录制/暂停/试听/保存状态显示可用快捷键，S:save完整可见。
- 设置卡片显示右对齐数值、亮度进度条；USB共享仍需手动开启，确认关闭前保留电脑安全弹出的提示。

- PlatformIO 构建通过：静态 RAM 90628 字节，Flash 1619917 字节。静态占用不代表SSH或媒体运行时剩余堆。
- 已有核心原生测试及文件管理原生测试通过，覆盖终端、MJPEG、键位、文件分页、复制取消、恢复与USB所有权。
- 本机 `.diagnostics/build_ui_preview.py` 提取实际页面绘图函数，并使用依赖库同款GLCD字形和模拟数据生成21个状态快照。文本屏幕边界与底栏截断检查通过；16页拼图已目视检查，无文件名/频谱/快捷键遮挡。
- 本地预览是简化绘图后端，未模拟LCD的8位色阶、真实硬件刷新、Wi-Fi/蓝牙连接或录音，不是实机截图。
- 实机仍需确认配色可读性、列表导航、录音/试听、SSH长行、键盘与USB共享回归。
- 已通过本次检测到的 COM12 烧录，全部写入哈希校验通过；上传后仍枚举下载端口，正常启动界面等待用户确认。

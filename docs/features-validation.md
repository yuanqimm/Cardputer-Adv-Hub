# 功能完善验证记录（更新至 2026-09-26）

## 已实现功能

- Keyboard 页面输入隔离，USB/BLE/双发模式，进入等待松键、退出释放，USB 保持按下，Opt 与 Fn 方向键映射。
- SSH 分阶段非阻塞调用、超时、端口参数类型修正、服务器指纹核验、输入队列、基础 VT100 屏幕；普通字符不再被导航抢占。
- SSH 增加异步 Wi-Fi 扫描与加密标记、W/S 选择连接、板载 WPA 密码输入、Wi-Fi 密码 NVS 记忆、最多 6 条成功连接历史配置及一键重连路径。
- Wi-Fi 连接生命周期与 SSH 会话分离；返回主页不会主动断开 Wi-Fi，顶部状态栏实时显示连接/未连接图标。
- Wi-Fi 成功后可在板上依次输入 SSH 主机/IP、用户名和密码；有历史或 SD 配置时仍可直接进入非阻塞 SSH 握手。
- SSH 建立前暂时释放 BLE 协议栈，SSH 退出或失败后恢复 BLE 广播；最终固件编译通过，SSH 实际握手仍需真实服务器验收。
- SD Storage 替代 Media Player：完整路径、多级目录、文件夹优先排序、64 项一批的目录分页，新建、复制文件、剪切/移动、重命名、删除文件/空目录、属性及 4 KiB 文本编辑。
- 任意目录选文件播放，音乐暂停继续、状态/文件读取进度/时长显示；输出应用实际音量增益，播放到尾停止；已移除旧固定目录索引。
- 原始 MJPEG/JPEG 播放，40 KiB 帧上限；不支持带音轨视频、MP4/普通 AVI 解码。
- 多红外配置、地址与命令范围校验；亮度/音量/帧率持久保存。
- 保持 N2 蓝牙身份、安全配置与缓冲屏幕显示；修改前快照位于 `.diagnostics/baseline-n2`。
- USB MSC 手动开启：Settings → USB SD sharing → Enter，开机默认关闭。先停止媒体、暂停设备端 SD 访问再开放介质；弹出后重新挂载文件系统。2026-09-26 用户确认“功能完成”，本项作为已验收基线保留。

以下保留为后续回归清单，不是本次逐项执行记录：

1. 冷启动并插入 USB：共享 OFF，电脑不能读取 SD，设备端媒体和配置可用。
2. Settings 选择第四项 USB SD sharing、Enter 进入，再 Enter 开启：共享 ON；电脑识别原有容量与文件，设备端媒体停止且无法重新播放，SSH/红外 SD 配置读取被阻止。
3. 无 SD 卡启动后尝试开启：提示 card unavailable，仍保持 OFF。
4. 电脑复制一个测试文件并回读核对；Fn+Q 返回主页后共享仍为 ON。
5. 电脑安全弹出：页面自动变为 OFF，设备重新挂载后可看到新增文件；随后可再次 Enter 开启。
6. Enter 请求关闭、N 取消：保持 ON；电脑弹出后 Y 关闭：OFF。重启后不恢复共享。
7. 回归 USB/BLE 键盘、断线重连和屏幕无闪烁；实际写入期间不进行拔线测试。

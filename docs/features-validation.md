# 功能完善验证记录（2026-09-20）

## 本轮完成

- Keyboard 页面输入隔离，USB/BLE/双发模式，进入等待松键、退出释放，USB 保持按下，Opt 与 Fn 方向键映射。
- SSH 分阶段非阻塞调用、超时、端口参数类型修正、服务器指纹核验、输入队列、基础 VT100 屏幕；普通字符不再被导航抢占。
- SSH 增加异步 Wi-Fi 扫描与加密标记、W/S 选择连接、板载 WPA 密码输入、Wi-Fi 密码 NVS 记忆、最多 6 条成功连接历史配置及一键重连路径。
- Wi-Fi 连接生命周期与 SSH 会话分离；返回主页不会主动断开 Wi-Fi，顶部状态栏实时显示连接/未连接图标。
- Wi-Fi 成功后可在板上依次输入 SSH 主机/IP、用户名和密码；有历史或 SD 配置时仍可直接进入非阻塞 SSH 握手。
- SD 使用完整路径、按类型过滤并排序，文件数改为 16 位并限制每目录 128 条。
- 音乐暂停继续、自然到尾换曲、状态/文件读取进度/时长显示；输出应用实际音量增益。
- 原始 MJPEG/JPEG 播放，40 KiB 帧上限；不支持带音轨视频、MP4/普通 AVI 解码。
- 多红外配置、地址与命令范围校验；亮度/音量/帧率持久保存。
- 保持 N2 蓝牙身份、安全配置与缓冲屏幕显示；修改前快照位于 `.diagnostics/baseline-n2`。

## 已执行的检查

- MinGW C++11 原生测试通过：终端分段 CSI/OSC、CR/BS/Tab、光标范围、滚屏、插入删除字符、UTF-8 替代符；MJPEG 分段帧、溢出及恢复；键位映射。
- PlatformIO 固件编译通过（本轮扫描/历史改动），静态 RAM 与 Flash 以编译输出为准。
- COM12 烧录完成并通过写入校验，正常启动后恢复 COM8。
- COM8 状态快照确认地址仍为 `E9:A8:B4:3E:2A:0F`，广播有效，无加密错误；可用堆 96892 字节，最低可用堆 96804 字节。这个状态尚未启动 Wi-Fi/SSH/媒体，不能代表负载时内存余量。
- 转码脚本命令行帮助检查通过，示例 WAV 已生成；未在本机运行 ffmpeg 转码。
